# Ear as a microphone, session 1 (the night before)

The same stimulus and decoder as [`../ear_mic2`](../ear_mic2/README.md), recorded
at 01:34 on 17 October 2026 with the top (AUX) electrode making no contact and a
tired subject: 24 plays of the 31.5 s *Alice* clip from the headset's speakers.
The averaged held-out reconstruction reached r 0.18 (shuffled null 95th
percentile 0.09, p 0.001), the single-play mean 0.037, and the shifted-EEG control
0.078 (p 0.044), so the night's result was above chance but with a control that
was not clean. Eleven hours later, with the top electrode on and the subject
awake, the same protocol gave r 0.36 with the control at chance; that session is
the one reported, and this folder is kept for the comparison. The audio of this
session is not kept here; the numbers are in `ear_mic_results.json` and the
figure in `ear_mic_figure.pdf`.
